# VCV Rack patches

A running logbook of my [VCV Rack](https://vcvrack.com/) explorations since
March 2020: mostly drones, generative sequences and other experiments in
getting modules to surprise me.

Patches are grouped by quarter (or by year, in the slower years). Each folder
has its own readme describing the patches it contains: what modules are
involved, how they are wired, and what the thing is supposed to sound like.
More recent folders also include a screenshot of the rack.

## Using the patches

Files are plain `.vcv` patches: open them from VCV Rack with *File > Open*.
Recent patches were made with VCV Rack 2.6.6, and the older ones with whatever
version was current at the time, so a patch may ask you to install missing
modules (or refuse to load one that no longer exists in the library).

I work with open source modules whenever I can, and with free ones when there
is no open source alternative. I do not use commercial modules, so every patch
here should be reproducible at no cost from the
[VCV Library](https://library.vcvrack.com/).
